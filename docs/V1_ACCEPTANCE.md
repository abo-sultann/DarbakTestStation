# V1 Acceptance Criteria

V1 is testable when it can:

1. Launch reliably on BlissOS Android 7+.
2. Import an APK through Android's document picker.
3. Read and display APK metadata without installing it.
4. Compare the candidate version with an installed package when present.
5. Launch an installed test app and record a test session.
6. Store a per-app Test Profile and checklist.
7. Provide a T3-oriented 1024x600 / landscape / RTL checklist.
8. Produce a concise test report separating Acer results from T3-required checks.
9. Operate without cloud services or embedded secrets.

A successful Acer test is never labeled as final T3 approval.
