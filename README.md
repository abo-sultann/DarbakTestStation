# Darbak Test Station

محطة اختبار تطبيقات **دربك** على جهاز Acer/BlissOS قبل الاعتماد النهائي على شاشة السيارة Allwinner T3.

## المسار المعتمد
GitHub / Build → Acer / Darbak Test Station → T3 Final Test

## أهداف V1
- استيراد وفحص APK.
- عرض package name وversion وminSdk وABI والحجم والصلاحيات المهمة.
- مقارنة APK بالنسخة المثبتة.
- تثبيت/تحديث/تشغيل وإدارة تطبيقات الاختبار ضمن حدود صلاحيات Android.
- Test Profiles منفصلة لكل تطبيق من تطبيقات دربك.
- فحص واجهة 1024×600 وLandscape وRTL.
- تسجيل نتائج التشغيل والأعطال ومؤشرات RAM/CPU المتاحة.
- إنشاء تقرير اختبار موحد يوضح ما تم اختباره على Acer وما يجب تأكيده على T3.

## قيود مهمة
Acer يعمل على Intel x86 بينما شاشة T3 تعمل على ARM Cortex-A7. نجاح التطبيق على Acer لا يعني اعتماده على T3. الاختبار النهائي للـGPS الحقيقي وBoot/Launcher وCAN/TPMS وسلوك النظام يبقى على شاشة T3.

## مبادئ المشروع
- Android 7+ قدر الإمكان.
- واجهة خفيفة مناسبة للمس.
- Offline-first.
- لا مفاتيح API أو Tokens أو بيانات سرية داخل المستودع.
- لا تضخيم للنسخة الأولى قبل استقرار الأساس.
- بيانات المحاكاة تُعرض دائمًا بوضوح على أنها بيانات اختبار وليست بيانات حقيقية.

## المراحل
1. **Foundation** — مشروع Android قابل للبناء + هوية دربك + شاشة رئيسية.
2. **APK Inspector** — استيراد وفحص ومقارنة APK.
3. **Test Runner** — تشغيل اختبارات أساسية وحفظ النتائج.
4. **T3 Profile** — اختبارات 1024×600 / RTL / Landscape وقيود الجهاز.
5. **Reports** — تقرير موحد لكل إصدار.
6. **Simulation** — GPS/سرعة/اتصال/CAN/TPMS التجريبي بعد استقرار V1.
